# Ticket sequence

The standard sequence for a ticket folder. Each step writes one artifact in that folder.

1. build: [[plan/context/build-work2.md]], which writes `<nn>-build.md`
2. review: [[plan/context/review-work2.md]], which writes `<nn>-review.md`
3. refactor: [[plan/context/refactor-work2.md]], which writes `<nn>-refactor.md`
4. doc: [[plan/context/doc-work2.md]], which writes `<nn>-doc.md`

Follow the shared rules in [[plan/context/ticket-rules.md]].
