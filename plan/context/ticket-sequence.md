# Ticket sequence

The standard sequence for a ticket folder.

1. Build follows [[plan/context/build-work2.md]] and writes `<nn>-build.md`.
2. Review follows [[plan/context/review-work2.md]] and writes `<nn>-review.md`.
3. Refactor follows [[plan/context/refactor-work2.md]] and writes `<nn>-refactor.md`.
4. Doc follows [[plan/context/doc-work2.md]] and writes `<nn>-doc.md`.

Follow the shared rules in [[plan/context/ticket-rules.md]].
