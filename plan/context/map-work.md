# Map work

## 1. Work

The work file is `plan/<slug>/map.md`. Write that file when the map step is about to be worked.

## 2. Map template

Copy these headings into the work file. Leave each pointer line as written. A pointer line names its target file.

```
# <name>

## 1. Problem

## 2. Solution

## 3. Scope
```

## 3. Fill

1. **Problem.** State the problem of the effort.
2. **Solution.** State the solution.
3. **Scope.** State the scope of the effort.

Done: `plan/<slug>/map.md` states the problem, the solution, and the scope under those headings.
