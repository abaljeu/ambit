# Ticket work 2

Make the ticket folder `issues/<nn>-<name>/`, for example `issues/01-accept-notices/`. In that folder create:

1. `CONTEXT.md`, which points to the sequence file in `plan/context/` for this kind of ticket. For a standard ticket that is [[plan/context/ticket-sequence.md]].
2. `<nn>-<name>-ticket.md`, written per [[plan/context/ticket-work.md]].

The handback is the ticket folder.
