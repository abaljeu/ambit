# Spec work

## 1. Work

The work file is `plan/<slug>/spec.md`. Write that file when the spec step is about to be worked.

## 2. Spec template

Copy these headings into the work file. Leave each pointer line as written. A pointer line names its target file.

```
# <name>

Map: [[map.md]]

## 1. User stories
```

## 3. Fill

1. **User stories.** Write a numbered list. Each item names one story in this shape: `<name> — As a <actor>, I want <feature>, so that <benefit>`.

Done: `plan/<slug>/spec.md` lists the named user stories, and the Map pointer names `map.md`.
