# Workspace git

Stage: spec
Summary: WorkspaceGit is the Actor that owns this protocol. The Actor receives Git Remote, Git Push, and Git Pull. Git Remote views and edits the remote, and that Command is how DataDir/{label} gets its remote. Git Remote has an option, default exclude, for Directory File / Ambit note paths named `.amb`, the same hard skip class as `.git/`. Most remotes must not receive Ambit notes. Git Push pushes the current Node and its Owned descendants and fails when no remote is set. Git Pull pulls the current Node and its Owned descendants and fails when no remote is set. Pull overwrites the local files it is pulling (the current Node and its Owned descendants that are being updated). On reject, Pull discards persisted bytes on conflicting files and accepts upstream for every conflicting file. That overwrite is how Pull accepts upstream on the conflicting files. Non-conflicting local files stay. Then Pull invokes the warm read. The warm read is DocumentWarm. The warm read overlays and keeps File identity. Pull does not take the cold read. The cold read refuses a text, name, or kind mismatch. WorkspaceGit owns DataDir/{label}. Git Push and Git Pull are the push and pull that DataDir starts toward the remote Git Remote sets. WorkspacePush stays git-receive-pack and WorkspacePull stays git-upload-pack. The Desktop map holds no remote and runs no git. Desktop push into the workspace stays WebDAV. persistGraphOps writes the Graph projection in that directory, and PostgreSQL stays the authority. Parse reconciles one file with the Nodes under that File Node. After a server HEAD move that is not Git Pull, Lazy Load marks the File Node Unparsed and leaves it for a later planParseFile warm read of that one File Node. Push rejects conflicting files (a path both sides changed since the merge-base) and accepts non-overlapping edits. That accept is not a fast-forward. Persist and the local commit remain when the push is rejected. Pull and Persist do not run at the same time. Persist runs only when the Graph is current with the file. When the Graph is not current, Nodes are marked Unparsed the same way as now.
