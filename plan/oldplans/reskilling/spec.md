# Reskilling

## User stories

1. Default sequence — As a person directing a feature, I want the sequence in [[../context/project-work.md]], so that later steps follow that sequence.
2. Project sequence — As a person directing an effort, I want `project.md` to list the sequence, so that I can include a context we have already defined.
3. Same feature — As a person directing an effort, I want a correction to re-enter the step whose outcome is wrong, so that the repair continues through the later steps.
4. Map — As a person directing an effort, I want the map to state the problem, the solution, and the scope, so that later steps build that outcome.
5. Stories — As a person directing an effort, I want the spec to list named user stories, so that each later step can point at a story.
6. Architecture — As a person directing an effort, I want story paths, a module map, and a slicing strategy, so that slicing cuts the feature in a known direction.
7. Slicing — As a person directing an effort, I want one ticket's scope decided from the arch and the spec, so that [[../context/ticket-work.md]] writes that ticket and hands it back.
8. Self-contained ticket — As an implementer, I want the ticket written by [[../context/ticket-work.md]], so that I can build from the ticket and the code.
9. Ticket type — As an implementer, I want a ticket to be `coding` or `bug-fixing`, so that I know whether the change adds behavior or corrects it.
10. Order — As an implementer, I want blockers to say which tickets come first, so that I start on a ticket whose blockers are met.
11. Build — As an implementer, I want the build to change the source the ticket names, so that the ticket's changes exist in the code.
12. Review — As a person directing an effort, I want one review per ticket scored against the stories that ticket named, so that a miss sends that ticket back to build.
13. Docs — As a later reader, I want `doc/current` and `doc/user` updated for the tickets whose stories were met, so that the docs match what was achieved.
14. Step work — As a person directing an effort, I want each step's work file to decide what gets built, so that the agent loads that step's work file.
