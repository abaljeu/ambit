## Answer

Alan, 2026-10-09.

Concept pages stay the complete big picture. Reference expands on those concepts with detail. Rewrite and move a page into Reference when that detail is needed.

A subject is in scope when Concepts or Reference names it. Link the doc page for that subject. [Actors](../../../doc/current/actors.md) can be linked. [Mailbox](../../../doc/current/mailbox.md) is how the program runs, so it has no link. An out-of-scope subject has no link. The glossary stays architecture-level. The user wiki uses the user's words.
