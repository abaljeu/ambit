# 14 — Cap of 200

**Status:** `defined`
**Type:** coding
**Blocked by:** None — section 1 **Find and Move** can start immediately

## Context

A short keystroke such as the letter e must not return the whole Graph. Step 1 stops the client search algorithm at 200 hits. That step does not start the Search Actor. [07 — Server completes the picture](07-server-completes-the-picture.md) is blocked by this section. Section 2 **Query cap** starts after [11 — Server evaluates](11-server-evaluates.md) only. Story path **Cap of 200** is [Online search architecture](plan/online-search/arch.md) §1.

## What to build

Find and Move stop at 200 hits on the client search algorithm. A query stops at 200. A query function may stop under 200. This ticket does not add expression spelling for that stop. There is no page.

### 1. Find and Move

This section is step 1. It can start now. Status for this ticket follows this section. [07 — Server completes the picture](07-server-completes-the-picture.md) starts when this section is done. This section does not start the Search Actor. The algorithm is [startSearch](src/Shared/ViewModelSearch.fs) and [takeResults](src/Shared/ViewModelSearch.fs). [searchNodes](src/Shared/ViewModelSearch.fs) uses that same stop.

1. [ ] Client stop — The algorithm returns at most 200 hits and then stops. Find and Move use that stop on the residence Graph. A later page does not add hits past 200.

### 2. Query cap

This section starts after [11 — Server evaluates](11-server-evaluates.md). It does not block section 1 **Find and Move**. It does not block [07 — Server completes the picture](07-server-completes-the-picture.md). The query stop stays on [Online search architecture](plan/online-search/arch.md) §2 item 2 **Query Actor**, State.

1. [ ] Query cap — The server returns at most 200 for a query and then stops. If the function asks for more than 200, the server stops at 200.
2. [ ] Lower stop — The query function may stop under 200. This ticket does not add expression spelling for that stop.
3. [ ] No page — The query does not page.
