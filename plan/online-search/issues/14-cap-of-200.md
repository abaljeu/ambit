# 14 — Cap of 200

**Status:** `defined`
**Type:** coding
**Blocked by:** [07 — Server completes the picture](07-server-completes-the-picture.md), [11 — Server evaluates](11-server-evaluates.md)

## Context

A short keystroke such as the letter e must not return the whole Graph. Find and Move already share one Actor from [07 — Server completes the picture](07-server-completes-the-picture.md). The Query Actor already evaluates on the server from [11 — Server evaluates](11-server-evaluates.md). Story path **Cap of 200** is [Online search architecture](plan/online-search/arch.md) §1.

## What to build

Find and Move together stop at 200 hits. A query stops at 200. A query function may stop under 200. This ticket does not add expression spelling for that stop. There is no page.

### 1. Search Actor

The cap stays on [Online search architecture](plan/online-search/arch.md) §2 item 1 **Search Actor** and §3 seam **Cap**.

1. [ ] Find and Move — The combined client hits and server hits stop at 200. Find and Move share that cap.

### 2. Query Actor

The query stop stays on [Online search architecture](plan/online-search/arch.md) §2 item 2 **Query Actor**, State.

1. [ ] Query cap — The server returns at most 200 for a query and then stops. If the function asks for more than 200, the server stops at 200.
2. [ ] Lower stop — The query function may stop under 200. This ticket does not add expression spelling for that stop.
3. [ ] No page — The query does not page.
