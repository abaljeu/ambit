# 01 — Docker deploy usefulness

**Type:** research
**Status:** defined
Blocked by: None

## 1. Question

Is a Docker deploy useful to the recorded goals?

The recorded goals are a spec to hand off and iterate on. The spec has two halves that name one Linux: compile the Server for Linux, and the Linux setup. The Linux setup is the machine and the setup the Server needs. Server is the server project and the server process. The main target is a fast-loading Azure server. Fast-loading is a startup goal and does not imply Docker on Azure. A docker container is a second target and is not locked. Whether the fast path is Docker within Azure is open. Usefulness is not known. The docker container stays unlocked until this result is in. This question comes before any other ticket.
