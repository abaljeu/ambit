# Grill locks 01–04

Date: 2026-09-26
Source: Alan in chat. Authoritative locks for [github-transport](../project.md). No product code.

## Vocabulary

Prefer **Workspace**, not “label.” Every Workspace’s DataDir work tree is a git work tree. Server-git vs desk: check if a remote exists. If a remote exists, the Server-git path is valid; else desk.

## 01 — Which Workspaces and remotes

Ticket: [01 — Which Workspaces and remotes](../issues/01-which-workspace-labels-and-remotes.md). Status `done`.

Any / every Workspace (all have git). Server-git applies when a remote exists — no allowlist, no special label.

Config lives in git on that work tree: `git remote` + current branch / upstream. **No separate Server branch map** in v1.

Pull and push the **same** tracked branch (FF-only already locked on Destination).

Checkout / switch branch / older commits are **out of this chart** (future).

## 02 — Actor command surface

Ticket: [02 — Actor command surface](../issues/02-actor-command-surface.md). Status `done`.

Person-facing Commands: **Load** and **Save** (same Ambit command names).

Explicit secondary pre-picks: **git Load** / **git Save** and **desk Load** / **desk Save**.

Plain Load/Save = git* when valid (remote), else desk*.

Do **not** inherit old workspace-git’s Git Remote / Git Pull / Git Push as the primary surface. Do not inherit non-FF accept.

## 03 — When pull and push fire

Ticket: [03 — When pull and push fire](../issues/03-when-pull-and-push-fire.md). Status `done`.

**No automatic** pull or push in v1 (no schedule, post-Persist, or post-Download git).

Person Load/Save (and explicit git*/desk*) only.

When a remote exists, plain Load/Save prefer **git first**.

All three Load forms **transfer files only** on this chart. WebDAV Upload/Download path **remains**.

Parse autonomy and Graph sync autonomy are **independent of this Project**. Do not adapt Load for parse or graph.

## 04 — Credential storage on Server

Ticket: [04 — Credential storage on Server](../issues/04-credential-storage-on-server.md). Status `done`.

Normal git way: Ambit does **not** store GitHub credentials in appsettings, user-secrets, Graph, or DataDir.

The Actor invokes `git`; **git** loads credentials (credential helper / host setup). On Server that is the host’s git, not a separate Ambit secret plumbing.
