Product code was not changed.

## Findings

### (a) Missing or partial

1. Persist-done does not mark Persisted. Spec: “Persist done — Mark that node Persisted only.” ([here-to-there.md](../here-to-there.md) §4 item 5). [writeDocumentsSoft](src/Server/DocumentPersistWrite.fs) and [persistGraphOps](src/Server/DocumentPersistChange.fs) write the artifact and stamp `updateTime` only. After a graph edit the owning special stays Unpersisted. Live-save on [FileAgent](src/Server/Core/FileAgent.fs) and [DbAgent](src/Server/Core/DbAgent.fs) is an existing persist-done site.

2. Discovery of a deleted member does not mark the Directory Node Unparsed. Spec: “A new member or a deleted member marks the Directory Node Unparsed.” ([here-to-there.md](../here-to-there.md) §4 item 3). [planDeletedInfo](src/Shared/dotnet/LazyLoadReconciliation.fs) trash-moves the node and does not write Unparsed on the parent Directory Node. Git pull finish uses this path (§4 item 4).

3. Client Load on Directory does not mark that Directory Node Unparsed. Spec: “Client Load on Directory — Mark the Directory Node Unparsed (re-process).” ([here-to-there.md](../here-to-there.md) §4 item 8). [reconcileDirectory](src/Server/LazyLoadReconciliationServer.fs) is the existing Load site.

4. Client Load on File does not mark that File Node Unparsed. Spec: “Client Load on File — Mark the File Node Unparsed.” ([here-to-there.md](../here-to-there.md) §4 item 9). Push onto the Parse stack is deferred; the mark is not. [planParseFile](src/Shared/dotnet/ImportDocument.fs) writes Current (Parsed) and does not write Unparsed at Load.

### (b) Behaviour not asked

None. No Parse actor, Core Persist stack, git Load retarget, or DocumentState retirement.

### (c) Implemented wrong

1. Parse apply marks Unpersisted. Spec: graph edit marks “Unpersisted only”; “Directory Parse done — Mark that Directory Node Parsed only.” ([here-to-there.md](../here-to-there.md) §4 items 2 and 6). [setText](src/Shared/GraphMutate.fs) / [replace](src/Shared/GraphMutate.fs) always call `markOwningSpecialUnpersisted`. [planParseFile](src/Shared/dotnet/ImportDocument.fs) and [parseDirInfoIfPresent](src/Shared/dotnet/LazyLoadReconciliationApply.fs) then SetDocumentState Current. The special ends Parsed and Unpersisted.

2. Discovery of a new member marks the parent Parsed. Spec: “A new member or a deleted member marks the Directory Node Unparsed.” ([here-to-there.md](../here-to-there.md) §4 item 3). [markAddedDocumentsUnparsed](src/Shared/dotnet/LazyLoadReconciliationApply.fs) and [WorkspaceUploadStructure.markParentCurrent](src/Shared/WorkspaceUploadStructure.fs) write Current on the parent Directory Node or Workspace Node (dual-write to Parsed).

Mikado dual-write of DocumentState on parse-axis writes is present. Persist has no DocumentState pole; persist-only writes leave DocumentState. GraphMutate is Shared; client graph-edit sites use it. [Here→There — step 1 locked](../here-to-there.md) §4.1 requires that until Core/mailbox lands.
