# Name and order the first Epics

Type: grilling
Status: resolved
Blocked by: 02

## Question

What are the first Epics, in order?

An Epic is a marketable user end-goal, not a feature (“read this kind of file”) or an interaction (“support this kind of edit”). Order mixes salience and closeness to realization; it may be somewhat arbitrary. Each named Epic is a standing file at `plan/roadmap/epics/<slug>.md`: a sequence of **Chapters** (named beats, not Project Stages). A Chapter follows [[plan/selective-client-loading/issues/17-represent-unloaded-child-lists-end-to-end.md]] raised one level: **What to build** names major features; the checklist points at Projects or issues and does not own them. Charting / spec / tickets stay on those Projects. Do not rank Projects as the Epic list.

Use the inventory from [[02-inventory-live-projects-and-roadmap-remainder.md]]. Do not invent one Epic per leftover `doc/roadmap` file.

Recommended (HITL confirm): grill breadth-first across user end-goals; keep the first list short; leave later Epics in the map’s Not yet specified.

## Answer

Person jobs, not software jobs. Outline capture is already met (no standing file). First open list, in order:

1. [[plan/roadmap/epics/work-with-text-files-from-anywhere.md]] — Work with my text files from anywhere (document that use via wiki Project issues).
2. [[plan/roadmap/epics/build-or-explore-a-wiki.md]] — Build or explore a wiki (our three wiki folders are Projects that take issues in service of Epics).
3. [[plan/roadmap/epics/create-and-publish-web-pages.md]] — Create and publish web pages.
4. [[plan/roadmap/epics/operate-a-pkm.md]] — Operate a PKM, seamlessly importing external data.
5. [[plan/roadmap/epics/agent-chat-managed-context.md]] — Agent chat with managed context.

Chapters uncharted except PKM: “Find what I wrote” is a Chapter of [[plan/roadmap/epics/operate-a-pkm.md]]. Later Epics stay in the map’s Not yet specified.
