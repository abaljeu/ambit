# Epic work

## Input

- [[chapter-work.md]]

## Process

1. Read [[chapter-work.md]].
2. Write the user narrative.
3. List each Chapter of this Epic.

## Output

The work file is `epics/<slug>.md`.

Copy these headings.

```
# <name>

<User narrative.>

## Chapters

- [[chapters/<slug>.md]]
```

A Chapter used by several Epics is listed on each of those Epics.

Done: the Epic states one user narrative and lists its Chapters.
