# Trackers

Which trackers this ticket touches.

Inputs: the ticket's one-line goal; the Project `spec.md` path; the Project `arch.md` path.
Depends: piece-goal, piece-arch, piece-obligations.

Output: the `**Trackers:**` line.

1. From the earlier outputs, name every tracker this ticket touches. Use these names: architecture, user spec, user manual, and project spec.

Done: the Trackers line lists each touched tracker by those names.
