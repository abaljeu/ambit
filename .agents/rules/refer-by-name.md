# Refer by name

Agent-produced planning artifacts must **number** and **name** every project, issue, section, and list item. Numbers are stable ids; the **name** is the title. In everything the human reads — narration, tickets, maps, specs — never refer by only the id or number; always include the name. A wall of `#42, #43, #44` is illegible; names read at a glance. The id and URL don't vanish — a name wraps its link — but they ride _inside_ the name, never stand in for it.
