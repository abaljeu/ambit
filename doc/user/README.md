# End-user wiki

This wiki explains how to operate Ambit. It uses concepts as the user sees them, and tasks in the App and in the Browser.  Guide gives high-level concepts and general usage patterns.  Reference is detail of every behavior and documentation of every command's detailed behavior.

These documents should not be complicated, nor should they lie about complexity.  Rather, if complexity shows up, this is a sign to look for ways to simplify the product.

One subject is one page. This home links that page.
