# Selection

Category: Reference

See Also:

[Commands](doc/user/reference/commands.md)

These commands grow or shrink the sibling selection.

## Selection up

Keys: Shift+Up arrow and `<`. While you are selecting or editing.

What it does: Extends or shrinks the selection by one sibling upward. While you are editing, the key runs only on the first visual line, commits the edit, and leaves that one node selected.

## Selection down

Keys: Shift+Down arrow and `O`. While you are selecting or editing.

What it does: Extends or shrinks the selection by one sibling downward. While you are editing, the key runs only on the last visual line, commits the edit, and leaves that one node selected.

## Select to Start

Keys: Shift+Page Up. While you are selecting.

What it does: Extends the selection to the first sibling under the same parent.

## Select to End

Keys: Shift+Page Down. While you are selecting.

What it does: Extends the selection to the last sibling under the same parent.
