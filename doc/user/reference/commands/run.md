# Run

Category: Reference

See Also:

[Commands](doc/user/reference/commands.md)

These commands start a node, stop that work, or check the outline.

## Run

Keys: Ctrl+Enter and Alt+Enter. While you are selecting or editing.

What it does: Starts the action on the focused node. When that node cannot run, Ambit shows an error.

Related: [Cancel](#cancel).

## Cancel

Keys: Ctrl+Shift+Enter. While you are selecting or editing.

What it does: Stops the live run on the focused node. The command palette hides Cancel when there is no run to stop.

## Check graph

Keys: none. Run it from the [Command palette](search.md#command-palette). While you are selecting or editing.

What it does: Checks ownership in the outline. A failing node becomes the selection, and Ambit shows the error.
