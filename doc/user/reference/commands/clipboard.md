# Clipboard

Category: Reference

See Also:

[Commands](doc/user/reference/commands.md)

These commands copy the selection, or insert another link to the same nodes.

## Copy content

Keys: `c`. While you are selecting.

What it does: Copies the selected nodes, including the nodes under them, to the clipboard.

## Copy as links

Keys: Ctrl+C and `C`. While you are selecting.

What it does: Copies the identifiers of the selected nodes to the clipboard, one on each line.

## Duplicate (link)

Keys: `D`. While you are selecting.

What it does: Inserts a link to each selected node just after the selection, and selects those new links.
