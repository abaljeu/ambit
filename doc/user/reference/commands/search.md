# Search

Category: Reference

See Also:

[Commands](doc/user/reference/commands.md)

These commands open a search for a node or for a command.

## Find

Keys: `/` and Ctrl+F. While you are selecting or editing.

What it does: Opens a search. The node you pick becomes the view root.

## Command palette

Keys: Ctrl+P and `p`. While you are selecting or editing.

What it does: Opens the commands you can run from the current mode. Type to narrow the list.
