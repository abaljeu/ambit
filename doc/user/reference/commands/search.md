# Search

Category: Reference

See Also:

[Commands](doc/user/reference/commands.md)

These commands open a search for a node or for a command.

## Find

Keys: `/` and Ctrl+F. Any Mode.

What it does: Opens a search. The node you pick becomes the view root.

## Command palette

Keys: Ctrl+P and `p`. Any Mode.

What it does: Opens the commands you can run in Selection Mode or Edit Mode. Type to narrow the list.
