# Commands

Category: Reference

See Also:

[Infinite Outliner](doc/user/guide/infinite-outliner.md)

Commands are the actions you run from the keyboard or from the command palette.

- [Cursor](doc/user/reference/commands/cursor.md) — move through the outline without rearranging nodes.
- [Folding](doc/user/reference/commands/folding.md) — open and close nodes.
- [Selection](doc/user/reference/commands/selection.md) — grow or shrink the selection.
- [Editing](doc/user/reference/commands/editing.md) — change the text of a node, or undo that change.
- [Move](doc/user/reference/commands/move.md) — rearrange nodes in the outline.
- [Clipboard](doc/user/reference/commands/clipboard.md) — copy nodes, or insert another link to them.
- [Files](doc/user/reference/commands/files.md) — open, load, save, and name files.
- [Search](doc/user/reference/commands/search.md) — find a node, or find a command.
- [View](doc/user/reference/commands/view.md) — change which part of the outline fills the page.
- [Run](doc/user/reference/commands/run.md) — run a node, stop that run, or check the outline.
