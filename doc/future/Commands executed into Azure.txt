2. Create PostgreSQL Flexible Server

Template command:

```bash
az postgres flexible-server create \
  --resource-group Amble_group \
  --name gambol-pg \
  --location "Canada Central" \
  --admin-user gambol_admin \
  --admin-password "<redacted>" \
  --sku-name Standard_B1ms \
  --tier Burstable \
  --storage-size 32 \
  --version 17 \
  --public-access 0.0.0.0
```

Executed successfully.

3. Create Gambol application database

```bash
az postgres flexible-server db create \
  --resource-group Amble_group \
  --server-name gambol-pg \
  --database-name gambol
```

Operational values for the next step

- App Service setting name: `DB_CONNECTION_STRING`
- Expected app connection string format:

```text
Host=gambol-pg.postgres.database.azure.com;Database=gambol;Username=gambol_admin;Password=<redacted>;SSL Mode=Require;Trust Server Certificate=true
```

- If Azure requires the fully qualified username instead:

```text
Host=gambol-pg.postgres.database.azure.com;Database=gambol;Username=gambol_admin@gambol-pg;Password=<redacted>;SSL Mode=Require;Trust Server Certificate=true
```
