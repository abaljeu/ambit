# End-user wiki

Labels: wayfinder:map

## Destination

A browsable wiki that describes the software for people who use it: what Gambol is, what a Graph and a Node are in use, and how to operate the App and Browser.

## Notes

- Charted from [[.scratch/roadmap/map.md]] after [[.scratch/roadmap/issues/02-inventory-live-projects-and-roadmap-remainder.md]].
- [[doc/]] today is engineer-facing (current baselines, roadmap, reference). It is not an end-user wiki.
- [[CONTEXT.md]] is the agent glossary, not user documentation.
- Sister Projects: [[.scratch/architecture/map.md]] (how it is coded and run), [[.scratch/marketing-wiki/map.md]] (uses, not how-to).

## Decisions so far

- Audience is people who use the software, not agents and not campaign readers.

## Not yet specified

- Home: a `doc/` subtree, a GitLab wiki, in-app Graph content, or another browse tree.
- Navigation and page set (what “describes the software” covers first).
- Which existing [[doc/]] pages are linked vs rewritten in user language.
- Boundary vs Architecture (internals) and vs Marketing wiki (uses).

## Out of scope

- Agent-instruction files under `.cursor/` and [[docs/agents/]].
- A marketing campaign.
- Implementing product features; this Project describes the software.
